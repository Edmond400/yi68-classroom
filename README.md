# 艺68班级服务站

清华大学美术学院艺68班的班级服务网站。六八六八，艺路生花。

**线上网站：[thuart68.cn](https://thuart68.cn)** · **许可证：[MIT](LICENSE)**

基于 React、TypeScript、Vinext、Cloudflare Workers 与 D1。公开页面无需登录；管理员使用独立账号维护内容和查看问卷。运行时无需大模型 API。

## 功能

- 班务日志、班级日程、重要通知与意见反馈。
- 生日调查：姓名、公历生日月日、集体生日参与意愿；防止双击或网络重试重复提交。
- 管理后台：维护班务和草稿，查看、筛选、统计生日答卷并导出 CSV。
- 私有附件：单文件最多 10 MiB，D1 按 512 KiB 分块保存；公开读取范围由内容发布状态决定。
- 一次性管理员初始化、密码派生存储、服务端会话校验、退出及改密后会话撤销。
- 管理员完整备份导出；另保留独立 Node / SQLite 部署路线。

## 本地开发

使用 Node.js 22.16 或更高版本、pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
cp .dev.vars.example .dev.vars
```

在本地生成随机初始化码，将其 SHA-256 摘要填入 .dev.vars 的 ADMIN_BOOTSTRAP_TOKEN_HASH。原始码由自己保管，不写入代码或公开 URL。

```sh
pnpm run db:migrate:local
pnpm run dev
```

首次访问 /admin/login，输入初始化码并设置至少 12 位的管理员密码，用户名为 admin。生日问卷路径为 /survey/birthday，结果管理路径为 /admin/surveys/birthday。

```sh
pnpm test
pnpm check
pnpm build
pnpm exec wrangler deploy --dry-run
```

## 部署

首次部署到自己的 Cloudflare 账号，见 [Cloudflare 部署说明](deploy/CLOUDFLARE.md)。需要创建自己的 D1 数据库并设置管理员初始化秘密；无需 R2。公开配置不包含生产数据库 UUID 或正式域名路由。

已有正式网站的维护、自动部署与本开源仓库的同步关系，见 [维护与发布](deploy/MAINTENANCE.md)。公开仓库目前用于源码发布，生产部署仍由既有私有分支触发。

## 数据与许可

本仓库发布源代码、数据库结构、测试及界面素材。真实答卷、名册、密码、会话、私有附件和备份保存在部署环境中，不包含在源码内。测试使用虚构数据。

## 活动参与档案与感谢奖励

- 学生入口 `/participation`：名册姓名、学号与班长私发的激活码首次激活；之后用学号和密码登录。个人记录、次数、申报状态和匿名编号只对本人及管理员可见。
- 管理入口 `/admin/incentives`：导入姓名学号（每行“姓名 学号”，班委加“班委”），标注班委，生成激活/重置码，建立任务，按实际日期批量勾选参与者，审核学生自主申报。
- 公开入口 `/rewards`：显示统计周期、倒计时、公开获奖姓名与匿名候选转盘回放，不公开个人次数、学号和完整参与明细。
- 跨天出勤按日期分别计次，同任务同日一次；每人每篇连续公众号任务最多两次，跨月不重置。班委仅在被标记为本职组织者的活动中不计奖，事实记录仍保留。
- 月奖每期最多三人，每人15元瑞幸礼品卡；边界并列等概率抽取剩余名额。连获两期后暂停一期，再恢复。月末北京时间13:00结算；十月首期从2026-10-01开始。漏记和迟审顺延下一期。
- 学期从2026-10-01开始，默认2027-01-15北京时间13:00截止，选前十名发班级文创，边界并列抽取；可在后台调整未公布的学期时间。月奖停评不减少学期有效参与。
- `worker.ts` 保留Vinext页面处理，并接入Cloudflare scheduled处理器；`wrangler.json` 的每分钟Cron执行到期检查与重试。即使无人访问网页也会结算；匿名结果接口也有幂等补偿。公开转盘播放已保存结果，刷新不会重抽。
- 新增结构只在 `drizzle/0005_participation_rewards.sql` 追加，未修改既有迁移。v3完整备份包含参与档案和固定结果，仍排除有效会话与待用激活码。恢复后未激活同学需重新领取码。

首次使用由管理员在网站后台录入真实名册及活动；源码不包含生产名册、真实出勤或任何有效激活码。卡券采购和微信发送由管理员执行，网站只记录获奖与发放状态。
