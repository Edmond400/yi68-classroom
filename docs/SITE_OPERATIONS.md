# 首页管理与站点运营监测

## 使用

主管理员从现有工作台进入 `/admin/home-config` 或 `/admin/analytics`。继续使用原有管理员会话；普通同学不需要登录。

首页管理支持独立显示/隐藏、上下排序、重点横幅/普通卡片、自定义标题/说明/按钮、北京时间展示截止、六个内容区块、实际首页预览及恢复默认。恢复默认先形成草稿，保存后生效。整份配置保存在 `settings.site_home_config_v1`，使用版本号比较并交换；并发冲突返回409，不能覆盖另一位管理员的保存。部署不会覆盖已保存的配置。入口注册于 `lib/site-modules.ts`。新增功能应先注册稳定ID，再加入路由映射。首页隐藏与业务关闭互相独立。

## 指标与边界

- 前端 `page_view` 才计入PV；资源、轮询、预加载、可识别机器人及遥测接口请求不计入PV。
- UV是随机匿名浏览器标识估算，不是人数。跨日范围使用去重表 `COUNT(DISTINCT visitor_hash)`，不累加每日UV。标识与去重数据最多保留30天；超出可准确去重的范围显示不可用。日级UV趋势可以长期保留。
- 匿名标识不与姓名、学号、账户或表单关联；运营事件表不保存访客标识。去重表只含日期、不可逆标识摘要及测试标记，不保存模块或路由。
- 页面底部“统计隐私”可关闭非必要访问统计；尊重 Do Not Track。关闭后业务处理结果与管理员审计仍继续记录。
- 上传成功在文件和必要业务索引写入完成后记录；同一文件/收据重试不重复计数。相册一次上传对应原图与预览两个文件，体积包含二者。多文件界面逐文件请求，操作次数以实际上传请求计。
- 下载为服务端响应请求，含Range与重试，不能解释为完成保存或独立下载人数。只累计可可靠测得的响应字节；缺少 `Content-Length` 的体积不会猜测。缩略图与普通图片浏览不计入主动下载。
- 相册ZIP在浏览器组装。清单请求记为 `export_requested`，原图请求记为主动下载响应；不伪造服务器ZIP响应。客户端最终文件是否保存不由服务器保证。图片征集的本地ZIP/CSV导出同样记录导出请求与管理员审计；实际图片传输另记下载响应，普通预览不算下载。
- CSV等服务器导出记录实际响应成功。原始日志导出上限10000条；超过上限可缩小日期范围。日级汇总和模块汇总另有导出。
- 登录成功依据实际认证响应；失败、限流、退出分别记录。学生及主管理员认证均覆盖。日志不包含密码、令牌、Cookie、请求体或完整IP。
- 响应耗时截至返回响应头，不含流传输结束。系统异常指标按HTTP5xx及任务失败计数，4xx作为预期拒绝另列；错误详情可能从多个层面描述同一请求，应按请求编号关联，不能相加。
- 所有日期筛选使用 Asia/Shanghai，自然日边界转换为UTC。数据库时间存UTC。
- 存储总览只查询业务文件元数据，包含附件、相册、图片征集、模拟汇报；不是Cloudflare账单。完整附件审计必须主动触发，不在每次打开总览时扫描R2。
- 监测只覆盖进入Worker的请求；边缘网络、DNS、Worker启动前故障及被拦截的前端事件不在保证范围内。最近入库、采集失败、任务状态及清理时间均可在后台查看；读取失败不会显示成零访问。

## 保留、可靠性与权限

迁移 `0025_site_operations.sql` 新增原始事件、日级聚合、匿名去重、独立管理员审计及限流表。原始事件30天，匿名去重最长30天，审计180天，日级聚合长期保留。SQL触发器在事件插入事务内完成汇总，重复事件ID无增量。清理只删除已原子汇总的原始数据，按1000条一批，重复执行安全。小时任务执行清理，与奖励结算、相册清理分别隔离。

Worker通过 `waitUntil` 处理遥测，写入失败不撤销已完成业务。前端接收接口限制2 KiB、事件白名单、严格字段校验、同源校验及每分钟限流。所有管理接口服务端校验主管理员；SQL参数绑定，CSV公式前缀转义。

所有重要后台写入及导出进入独立审计，记录管理员内部标识、固定操作代码、目标模块、结果及不含正文的摘要。公开版本不含生产数据或私有提交历史。

## 部署与验证

可使用 Cloudflare GitHub 构建或 Wrangler 部署。`pnpm build` 包含类型检查、运营专项测试和现有关键业务回归；`pnpm deploy` 先执行兼容的D1迁移再部署Worker。保留原D1/R2绑定、域名与定时任务。

`tests/site-operations.test.mjs` 覆盖增量迁移、配置并发/持久化/到期、管理权限、匿名事件校验/去重、跨日UV、测试隔离、时区、下载与业务计数、采集故障隔离、保留清理及CSV保护。

设置自己的 `YI68_ACCEPTANCE_ORIGIN` 后，手动运行 `pnpm accept:site-operations`，使用你自己的构建环境已有权限进行真实生产验收：临时测试会话、合成测试账户、草稿相册、真实R2上传下载、实际登录/失败/退出、配置操作及恢复、统计和CSV。测试事件使用短期测试标记，默认指标排除。测试业务记录、文件、会话、标记均在finally中清理；不读写普通同学的提交，不读取或修改生产密码。结果以安全摘要保存在 `settings.site_operations_v1_verified` 并写入构建日志。

新增监测数据从迁移及部署时开始积累，不补造历史数据。上线前和未来日期在趋势及CSV中留空；上线当天仅含开始采集后的部分。回滚Worker时保留兼容的新表，不做破坏性数据库回滚。

生产受控异常检查 `/api/admin/operations-check` 同时要求主管理员认证、同源请求及十分钟验收标记；窗口之外拒绝执行。检查只返回当前测试请求的500响应，不改变业务数据或制造服务中断。
